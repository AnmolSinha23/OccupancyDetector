# Smart Room Occupancy Detection from Environmental Sensors

**Advanced Programming Lab (Python) Project | CSE-3006**  
**Department of Computer Science & Engineering, IIIT Bhopal**  
Based on the research paper:  
*Candanedo & Feldheim, "Accurate occupancy detection of an office room from light, temperature, humidity and CO2 measurements using statistical learning models", Energy and Buildings (2016).*

---

## 📌 Project Overview
This project predicts whether an office room is **Occupied (1)** or **Empty (0)** using non-intrusive environmental sensor readings (Light, CO2, Temperature, Humidity). It avoids privacy-invasive sensors (cameras/microphones) and implements transparent, explainable machine learning models suitable for edge IoT deployments.

### Key Contributions Beyond the Original Paper:
1. **Systematic Sensor Ablation:** Leave-one-sensor-out and single-sensor analysis to find the minimal viable hardware sensor set.
2. **Causal Temporal Trend Features:** Strictly backward-looking 5-minute CO2 slope and rolling Light averages, preventing look-ahead data leakage.
3. **Environmental Shift Evaluation:** Robustness comparison between Door-Closed (Test 1) and Door-Open (Test 2) conditions.
4. **Leak-Free Chronological Validation:** Hyperparameter tuning using time-ordered splits rather than random k-fold shuffling.
5. **Interactive Web Application:** Real-time Streamlit dashboard (`app.py`) for live prediction and scenario simulation.

## 🚀 How to Run the Project

### Option A: Run Everything with One Command
To execute the complete end-to-end pipeline (download, inspection, EDA, training, ablation, trend features, hyperparameter tuning, and model saving):
```bash
python run_all.py
```
*Total execution time: ~15 seconds.*

---

### Option B: Run Individual Steps Sequentially

#### Step 1: Download and Inspect Data
```bash
python src/data_loading.py
```
*Downloads the UCI ID 357 dataset, parses timestamps, and prints shape, dtypes, null values, and class balance.*

#### Step 2: Exploratory Data Analysis & Plots
```bash
python src/exploration.py
```
*Generates and saves time series, class balance, and correlation heatmaps to `outputs/figures/`.*

#### Step 3, 4, 5: Train Baseline Models, Evaluate Metrics & Explainability
```bash
python src/baseline_models.py
```
*Trains Decision Tree, Logistic Regression, and Random Forest. Evaluates on Test 1 and Test 2. Saves metrics CSV, confusion matrices, Random Forest feature importance, and Decision Tree visual and text rules (`outputs/figures/decision_tree_rules.txt`).*

#### Step 6: Sensor Ablation Study (Contribution 1)
```bash
python src/sensor_ablation.py
```
*Evaluates leave-one-out and single-sensor models on both test files. Saves `ablation_metrics.csv` and `ablation_study.png`.*

#### Step 7: Causal Trend Features (Contribution 2)
```bash
python src/trend_features.py
```
*Calculates 5-minute CO2 change and 5-minute rolling Light average strictly using past readings. Saves `trend_metrics.csv` and `trend_features_comparison.png`.*

#### Step 8: Hyperparameter Tuning (Chronological Validation Split)
```bash
python src/hyperparameter_tune.py
```
*Splits training data into 75% sub-train and 25% validation by time. Evaluates `max_depth` to prevent overfitting.*

#### Step 9: Optional Histogram Gradient Boosting Reference
```bash
python src/optional_boosting.py
```
*Evaluates `HistGradientBoostingClassifier` as a modern tabular baseline.*

---

### Step 10: Launch the Interactive Streamlit Web Demo
```bash
streamlit run app.py
```
Open `http://localhost:8501` in your browser.  
- Adjust Light, CO2, Temperature, and Humidity sliders.
- Automatically calculates physical `HumidityRatio`.
- Displays real-time **OCCUPIED** or **EMPTY** badge with confidence probability.
- Test edge cases using pre-configured presets (e.g., "Empty room with lights left ON").
